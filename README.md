FoodHub-System

Food delivery management system built using C# Windows Forms and SQL Server.

Description

FoodHub System is a desktop-based food delivery management application developed to manage customers, food orders, and database operations.

Features

- User registration and login
- Customer management
- Food ordering management
- Dashboard interface
- Database integration using SQL Server

Technologies Used

- C#
- Windows Forms
- SQL Server
- Visual Studio
